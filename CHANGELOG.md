# Changelog

All notable changes to AI-Devkit are documented in this file.

## 0.1.0 - 2026-09-28

Initial documented project baseline. This is not a tagged or licensed public release.

### Added

- Six developer skills for codebase mapping, API integrations, developer documentation, prompt engineering, MCP server work, and plugin packaging.
- Five everyday skills for decision support, research briefs, writing editing, learning coaching, and current news briefings.
- Four financial education and scenario workflows for investing, budgeting, home-buying mechanics, and debt or loan comparisons.
- Fifteen focused custom-agent definitions that support bounded investigation, implementation, review, verification, evaluation, and scenario analysis.
- Optional private-profile templates and setup documentation with public-safe placeholder data, strict trust boundaries, and opt-in profile updates.
- Collision-safe instructions for installing skills and custom agents into a personal Codex environment.
- Financial safety boundaries that require visible educational-use disclaimers and prohibit recommendations or action directives.
